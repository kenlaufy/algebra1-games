Teacher guide: Balance Workshop

A 12-level game for solving linear equations in one variable. Students keep a balance scale level while they isolate x, moving from pictures to algebra tiles to symbols.

Learning goals

By the end of the activity, students can:

  • Explain why an operation must be applied to both sides of an equation to keep it true.
  • Choose an efficient sequence of inverse operations to isolate a variable, including variables on both sides.
  • Solve equations with negative numbers and negative solutions, and check a solution by substitution.

How the game works

Students build a move (+, − or ÷, a number, and either 1 or x) and apply it to one pan. The scale tips until they apply the same move to the other pan. A level is solved when one pan holds a single x and nothing else. Stars reward solving in the fewest moves (par).

StageLevelsWhat students seeWhat it builds
1 · Mystery boxes1–4Cardboard boxes and blocks on a scale. The equation stays hidden until the level is solved.The balance idea: whatever you do to one side, you do to the other.
2 · Tiles and symbols5–8Algebra tiles (red = negative) and the live equation under the scale.Zero pairs, negative numbers, negative solutions, dividing by −1.
3 · Symbols only9–12Only the equation. Each move applies to both sides automatically.Fluent symbolic solving with variables on both sides.

Lesson plan (20 minutes)

  1. Launch, 3 min. Project level 1. Ask: "What could we do so the box is alone, but the scale stays balanced?" Take two or three ideas, then try one together. Let the class see the scale tip when only one pan changes.
  2. Play, 10 min. In pairs, one student controls the game and the other must predict the next move out loud before it's made. Switch roles every level. Goal: reach level 8. Early finishers go for 3 stars on every level.
  3. Translate, 4 min. Each pair copies one win screen's "written in math" steps into their notebook, then writes one sentence explaining the first step (for example, "I subtracted 3 from both sides so the equation stays true").
  4. Exit ticket, 3 min. Use the printable exit ticket below, on paper with no game.

Discussion questions

  • Why does the scale tip when you change only one pan? What does that mean for an equation?
  • On level 3, does it matter whether you subtract 1 or divide by 2 first? Why can't you divide first?
  • Level 7 has a negative answer. How can a box "weigh" a negative amount?
  • On level 8 you get −x = −3. Is that solved? What move finishes it?

Common misconceptions and what the game does

MisconceptionWhat happens in the game
Doing an operation to only one sideThe scale tips, the mascot looks worried, and the game asks for the same move on the other pan.
Dividing only one term, e.g. (2x + 1) ÷ 2 = x + 1The game refuses: "You can't split 2x + 1 into 2 equal groups." Students must subtract first.
Sign errors with negativesRed tiles make the negatives visible; adding +1 to −3 cancels one zero pair.
Stopping at −x = 3The game doesn't count it as solved and hints: "What could flip its sign?"
Believing solutions must be positiveLevel 7 solves to x = −4. The win screen checks it by substitution.

Note for level 7: the scale tilts using the true value of x. Because x = −4, the blue tiles count as negative weight, so a pan with more tiles can rise. This is a good discussion point, but it can surprise students at first.

Exit ticket

Balance Workshop exit ticket   Name: ______________________

  1. Solve and check: 3x + 5 = 20
  2. Solve and check: 2x − 7 = 5x + 8
  3. Maya says the first step for 4x + 6 = 18 is to divide only the 4x by 4. Is she right? Explain using the idea of a balance scale.

Exit ticket answers

  1. x = 5. Subtract 5 from both sides (3x = 15), then divide both sides by 3. Check: 3(5) + 5 = 20.
  2. x = −5. Subtract 2x (−7 = 3x + 8), subtract 8 (−15 = 3x), divide by 3. Check: 2(−5) − 7 = −17 and 5(−5) + 8 = −17.
  3. No. Dividing only one term changes one side differently from the other, so the scale tips and the equation is no longer true. She could subtract 6 from both sides first, or divide every term on both sides by 4.

Differentiation

  • Support: start every student at level 1 and let pairs talk through each move before applying it. The "How to play" button repeats the instructions.
  • Extension: earn 3 stars on all 12 levels, then write a new equation for a partner and solve it on paper using the same moves. Challenge: solve ax + b = c for x.

Technical notes

  • Runs in any current browser (Chrome, Edge, Safari, Firefox), including school Chromebooks and iPads. Works on a projector.
  • No accounts and no student data. Stars are saved only in the browser on that device; students can clear them with Levels → Reset my stars. See the privacy page.
  • Fully playable with a keyboard: use Tab to reach the buttons, and the Left pan / Right pan buttons instead of clicking the scale. The scale has a text description for screen readers.
