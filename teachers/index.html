Algebra I teacher guides

One game for every Model Algebra I standard. Every game has a guide with the standard's official wording, a 20-minute lesson plan, common misconceptions, an answer key for all 12 levels, and a printable exit ticket.

Classroom tips

Send students to one level

Add ?level=5 to the end of a student link to open level 5. Each guide's answer key links to every level, which also helps when projecting.

Timing

Levels 1–8 take about 15–20 minutes, so a game fits a warm-up or a station. All 12 levels take about 30 minutes.

Stars and privacy

The site saves stars in this browser. Teachers can collect progress through their school’s existing tools. See the privacy page for what the codes and exports contain.

Calculator

Every game has a calculator button. Turn it off for a class in its settings, or add ?calc=0 to a student link.

Classes

Class dashboards live in your browser. Download a backup from the Classes page to move them to another computer.

Devices

Runs in any current browser: Chromebooks, iPads, laptops and phones. Every control works with a keyboard.
