For teachers

Every game has a guide with the standard's official wording, learning goals, a 20-minute lesson plan, common misconceptions, an answer key for all 12 levels, and a printable exit ticket.

Using the games in class
  • No accounts, installs or student data. Share the game link.
  • Each game takes 15–20 minutes for the first 8 levels, so it fits a warm-up or a station.
  • Add ?level=5 to a game's address to send students straight to a level.
