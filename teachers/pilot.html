Sample lesson: solving equations by keeping balance

Grade 9 Algebra I · 20 minutes · MA AI.A-REI.B.3

Students solve a linear equation by applying the same operation to both sides, then explain why each move preserves the solution.

Open student lesson Full teacher guide

  1. 3 min. Display level 1. Ask students what would happen if they removed weight from only one side.
  2. 9 min. Have students play levels 1–4. Ask partners to name the operation and predict the next equation before applying it.
  3. 4 min. Discuss how a move on the scale shows up in the written equation. Ask a student to verify a solution by substitution.
  4. 4 min. Have students answer the question below on paper or in your usual classroom tool. It also appears after level 4.

Exit question

In x + 4 = 9, a classmate subtracts 4 from the left side only and writes x = 9. What should they write instead? Why must they subtract 4 from both sides?

What to look for in student answers

Subtract 4 from both sides to get x = 5. The two sides were equal, so taking away the same amount keeps them equal. Accept a correct explanation using the scale or substitution. For example, 5 + 4 = 9, while 9 + 4 ≠ 9.

Technology and data review

Access
A current browser with JavaScript and browser storage enabled. Open the GitHub Pages site on the school network and check the sample lesson on a managed device before assigning it.
Data handling
The site stores progress and class records in the browser profile. Hand-ins, CSVs, and backups can contain classroom aliases and progress. GitHub Pages logs visitor IP addresses. See the privacy page for the full data flow and deletion options.
Shared devices and backups
Use a separate browser profile for each student. Stars are shared across classes in the same profile. Dashboard records live in the teacher’s current browser. Keep any exports and backups in approved school storage.
Support
Report general bugs through GitHub issues. Include the game, level, browser, and steps to reproduce. Keep student details and progress codes out of public reports.

Accessibility in the pilot

What is in place: visible focus on buttons and fields, written feedback after each move, and reduced motion when the device asks for it. Keyboard controls vary by game, so check the game you assign.

What is checked: automated layout checks run every page and every game level at 320, 375, 768 and 1280 px, looking for sideways scrolling and cut-off text. The game checks play every level through its real controls.

What is not yet done: there is no formal WCAG audit or accessibility conformance statement. Graph games ask students to select points on a diagram, which is the hardest part to do with a keyboard, a screen reader or touch. Try those levels with the student's own setup before assigning them.

Every teacher guide includes a printable exit ticket and answer key, so a student who cannot use a level can still work on the same skill.
