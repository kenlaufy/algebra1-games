Privacy

Algebra 1 Games does not collect, store, or share any information about students or teachers.

Last updated November 21, 2026

  • No accounts. Nobody signs up or logs in.
  • No personal information. The games never ask for names, emails, or any other details.
  • No cookies, analytics, or tracking.
  • No ads.
  • No third-party services. Fonts and images are served from this site, so a student's browser doesn't contact any other company while playing.

What stays on the device

To remember progress, a game saves a small note in the browser's local storage on that device only. It is never sent anywhere.

Saved itemWhat it holds
a1g-stars-gameStars earned on each level of that game
a1g-help-gameWhether that game's "How to play" screen has been shown
balance-workshop-stars, balance-workshop-seen-helpThe same two items for Balance Workshop

To delete it, open a game's Levels screen and choose Reset my stars, or clear the browser's site data.

Hosting

The site is hosted on GitHub Pages. Like any web host, GitHub receives standard technical information when a page is requested, such as the visitor's IP address, and may log it for security purposes. Algebra 1 Games has no access to those logs. See the GitHub General Privacy Statement.

Questions

Questions about privacy or the games can be raised on the project's GitHub issues page.
