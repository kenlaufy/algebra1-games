Privacy

Algebra 1 Games has no account system or central database. The browser stores game and class data locally, and teachers can collect progress codes through an approved classroom tool.

Last updated November 22, 2026

  • No accounts. Nobody signs up or logs in.
  • Class identifiers. The class page asks for a nickname or roster number. Use a classroom alias in place of a full name, email address or school ID.
  • No cookies, analytics, or tracking.
  • No ads.
  • Site requests. GitHub Pages serves the site, including fonts and images. The games do not load third-party trackers or embedded services.

What stays on the device

Game progress and class records are saved in the current browser profile. Use separate browser profiles on shared devices. The same profile shares its stars across classes and users.

Saved itemWhat it holds
a1g-stars-gameStars earned on each level of that game
a1g-help-gameWhether that game's "How to play" screen has been shown
balance-workshop-stars, balance-workshop-seen-helpThe same two items for Balance Workshop
a1g-last, a1g-roleThe last game played (for "continue") and whether the student or teacher version is showing
a1g-classOn a student's device: the class code, class name, assigned games and the nickname or number the student typed
a1g-classesOn a teacher's device: the teacher's classes and the progress codes they pasted in

Reset my stars in a game clears stars for that game. Leave class removes the current class from the student browser. Teachers can remove a student or delete a class in the dashboard. Clearing the browser’s site data removes local records. Manage copies already handed in, exported or backed up through your school’s retention process.

Classes

Classes work without accounts or a server. A student joins by typing a class code and a nickname or roster number, which is saved only on their device. When the teacher asks, the student makes a progress code: a line of text containing the class code, the nickname, the hand-in time, and any game stars saved in that profile. The site doesn't send it anywhere. The student hands it in through whatever the class already uses, such as Google Classroom, and the teacher pastes it into the Classes page, which keeps it only in the teacher's browser. A progress code can be read by anyone who has it. Share it privately with the teacher. Dashboard CSVs and backups contain classroom aliases and progress, so keep them in school-approved storage.

Hosting

The site is hosted on GitHub Pages. GitHub says it logs visitor IP addresses for security. See GitHub Pages data collection and the GitHub General Privacy Statement.

Questions

For general questions, use the project's GitHub issues page. Keep student information and progress codes out of public issues.
